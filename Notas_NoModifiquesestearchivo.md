# Notas
## Variables
- Puedo Indicar el Nombre después poniendo solo el Nombre de la variable sin la Palabra reservada Let.
- No puedo Iniciar una Variable con Números, solo con Letras o Guiones Abajos como este _ .
- Live Server Es una extensión Recomendada.
- Usar Nombres para Variables que pueda recordar Después.
- Usar camelCase que es Iniciar el Nombre de una sub palabra adentro de la Palabra o del Nombre de la Variable pero el Nombre de la variable no iniciar con Let
### Primitivos
- Let puede hacer Let Nombre, Nombre2  y así Nombre y Nombre2 serían variables Diferentes pero con un Mismo Let.
- Las Variables Primitivas son Number, String, Boolean, Undefined y Null, se caracterizan por ser Rapidas y Fijas son Stack, Cuando Buscas encuentras directamente al Dato.
- Los Números son Tipo Primitivos Number, no requieren Comillas Simples ni Dobles.
- Las Letras o Texto Alfabetico con llamados strings y requieren Comillas Simples o Dobles
- Las No definidas son UnDefined y son Primitivos, no Requieron Comillas por que no hay Valor
- Las SI/NO o True/False son boolean y no requieron Comillas
- Los Nullos o Variables que se les asigno = Null son Tipo Null Primitivas
### de Referencia 
- Las Variables de Referencia son  Array, Object, Function, Clases, son Dinamicas, Puede crecer y son Heap, son Lentas y son de Referencia, uno al buscar encuentra referencias al Datos no Directamente al Dato.
- Puedo Crear Let con varios let adentro pero en realidad son datos en conjunto, los escribo con { dato:valor }
- si quiero eliminar un dato uso delete let que lo contiene. let a eliminar un ejemplo es personaje.serie
 ## Constantes
- Usar Const casi Siempre pero usar Let cuando es Necesario cambiar los valores o los valores son Dinamicos, 
- Let es Variable y Dinamico Su Valor pero Const es Constante y si lo intentas cambiar suelta error 
- Usaremos Tipado Dinamico , JS usa este y es muy facil de Cambiar
- Usar las Let y Const de Manera adecuada  
- Usar console.log(typeof variable) cuando necesitemos saber el Tipo de Variable Primitiva  
- Usar los // para comentarios de una linea, solo cuenta desde los Dobles Slash hasta la Derecha 
- Usar los /* para comentarios de muchas lineas, usar /** para que VS Code Ayude poniendo asteriscos en las lineas que escribimios haciendolo más legible
